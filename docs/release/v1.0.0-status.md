## Distribution limits

The DMG is arm64 and requires macOS 14 or later. Automatic updates are not included. Full Claude Code/Grok Bot live qualification, physical multi-monitor checks, and clean-machine installation remain tracked in the [roadmap](../roadmap.md).

The six GitHub Actions Apple secrets are not configured. Local signing and notarization can publish the first release without exporting the signing certificate into CI; future automated tag releases still require that setup.

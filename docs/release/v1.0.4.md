# ScreenClip 1.0.4

The menu bar popover lists the reports behind each count, the queue shows newest first, and fixes from a full review of everything since 1.0.1. This is the first version that installs itself on copies running 1.0.3.

## New

- **The popover lists what it counts.** Click **Open**, **Needs you** or **To retest** to list those reports under the counts, newest first. Click one to open it in the queue on the same list. Before, the popover always showed the five newest reports, whatever their status.
- **Newest first everywhere.** The queue's report list is now newest first, like the popover and the composer's **Issue** menu.

## Fixes

- **Open queue** opens the queue as you left it: it no longer clears your project filter, agent filter or search, or closes the report you were reading.
- Verifying, archiving or answering a report no longer moves the queue to another list. The report closes and the list you were working through stays.
- Agent summaries keep their line breaks. A summary written one item per line showed as a single run-on line since 1.0.3.
- **Text task** from the popover credits the app you were testing, not ScreenClip, so it routes to the right project.
- **Continue** on a report whose worktree was removed first picks up commits pushed to its pull request from elsewhere, instead of failing at the push. If the two sides diverged, it stops and says so before the agent starts.
- Before / After screenshots in a private repository's pull request preview load even when the Git remote spells the owner or repository in different letter case.
- A pull request that was deleted, or that your GitHub account cannot see, now says so in its preview instead of showing a generic error.
- A pull request preview that fails to load (offline, `gh` signed out) is not fetched again for a few minutes while you scroll the queue.
- The menu bar badge uses the same rules as the queue's **All open** and **Needs you** lists.

## Install

If you have 1.0.3, ScreenClip installs this update on its own: it shows **Update to 1.0.4** in the menu bar popover once it is downloaded, or installs it the next time ScreenClip quits. **Check for Updates…** in the popover's **⋯** menu checks right away.

From 1.0.2 or earlier, download **ScreenClip.dmg** from this release, open it, and drag **ScreenClip** into **Applications**, replacing the older version. Your queue, projects and settings are kept. Requirements, privacy and limits are otherwise unchanged from the [1.0.0 release notes](v1.0.0.md): Apple Silicon and macOS 14 or later. The [privacy policy](https://screenclipai.com/privacy) now describes the daily update check.

The app and disk image are signed with Developer ID, notarized by Apple, and stapled. Updates are also signed with ScreenClip's update key, and the app refuses any that are not. To verify the download, place `ScreenClip.dmg` and `SHA256SUMS` in the same folder and run:

```sh
shasum -a 256 -c SHA256SUMS
```

# ScreenClip 1.0.2

Text-only reports, a faster way to start them, and merging a pull request from the report.

## New

- **Text note.** The menu bar popover has two buttons, **Screenshot** and **Text note**. A text note files a report with no screenshot, for things you can describe faster than you can capture.
- **Read and merge the pull request in ScreenClip.** A report with a pull request shows its formatted GitHub description and a **Merge pull request** button, even when automatic merge is off. Before merging, ScreenClip checks that the pull request still has the commit it validated, that local validation passed, and that GitHub's checks and required reviews allow it. GitHub refuses the merge if someone pushes in the meantime.
- **Reuse the last agent.** Each project can start new reports with the agent, model and effort you last submitted, instead of the project default. Turn it on in the project's settings.

## Fixes

- A pull request with no GitHub checks can be merged by hand only after its checks have stayed empty for three minutes, so a merge cannot land before CI starts after a push.
- Confirming a merge while ScreenClip is busy updating that pull request now says so, instead of doing nothing.
- Grok Bot: when a report mixes text notes and screenshots, each `capture-<n>.png` matches its note.
- A text note started from the popover is credited to the app you were in, not to ScreenClip.
- Agents are told which captures have a screenshot attached.
- Choosing the current project or issue again keeps the agent you picked.

## Install

Download **ScreenClip.dmg** from this release, open it, and drag **ScreenClip** into **Applications**, replacing the older version. Your queue, projects and settings are kept. Requirements, privacy and limits are unchanged from the [1.0.0 release notes](v1.0.0.md): Apple Silicon, macOS 14 or later, and updates by downloading a newer disk image.

The app and disk image are signed with Developer ID, notarized by Apple, and stapled. To verify the download, place `ScreenClip.dmg` and `SHA256SUMS` in the same folder and run:

```sh
shasum -a 256 -c SHA256SUMS
```

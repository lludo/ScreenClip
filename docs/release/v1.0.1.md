# ScreenClip 1.0.1

A maintenance release with a tidier composer, an agent model and effort picker, and better tracking of pull requests you merge yourself on GitHub.

## Composer

- The **Agent** menu now picks the model and reasoning effort along with the agent, for example **Claude Code ▸ Opus ▸ Extra high**. The button shows the result, and default rows name the actual default when it is known.
- The header is one line at about half the height, with the app and site (for example "Safari · localhost") on the right.
- **Agent** and **Submit** line up on the same margin, with **Save draft** beside **Submit**.
- The **Issue** menu lists existing issues newest first.

## Pull requests merged on GitHub

- A report at **Needs you** or **Failed** whose pull request you merge on GitHub now switches to **Merged**, with the usual notification and **To retest** entry. **Refresh PR status** is available on those reports too.
- If you added newer evidence to the report after its pull request was opened, only the work the pull request holds is marked fixed; the newer evidence goes back to the queue for a new fix.
- A report whose agent run could not be confirmed is left for **Reconcile** instead of being marked merged.

## Fixes

- **Allow and automate this project** applies only to the report the request came from.
- A Codex fix recovered after a restart is no longer marked "Worker disconnected" if Codex disconnects during validation.
- The **Open at login** toggle shows the real state when macOS refuses the change.
- A follow-up's agent label no longer names the wrong Codex model, and the Codex model list clears when Codex disconnects.
- Faster typing in the composer and smoother progress updates: the Grok Bot connection and capture images are no longer re-read on every redraw.

## Install

Download **ScreenClip.dmg** from this release, open it, and drag **ScreenClip** into **Applications**, replacing 1.0.0. Your queue, projects and settings are kept. Requirements, privacy and limits are unchanged from the [1.0.0 release notes](v1.0.0.md): Apple Silicon, macOS 14 or later, and updates by downloading a newer disk image.

The app and disk image are signed with Developer ID, notarized by Apple, and stapled. To verify the download, place `ScreenClip.dmg` and `SHA256SUMS` in the same folder and run:

```sh
shasum -a 256 -c SHA256SUMS
```

# ScreenClip 1.0.0

File bugs as you go, without breaking your flow.

ScreenClip is a native Mac menu bar app that turns screenshots and observations into coding-agent reports, keeps the conversation and fix together, and helps you track what is ready to retest.

## Capture and report

- Capture a region from any app with **⌘⇧2**, or choose your own shortcut.
- Annotate, redact, and add a note before submitting. A screenshot alone is enough.
- Keep related observations together with follow-up captures, notes, and image attachments.
- Route reports to a project using the app or browser context, with manual correction before sending.

## Work with your coding agent

- Connect **Codex CLI**, **Claude Code**, or a **Grok Bot webhook**.
- Codex and Claude Code work locally in isolated Git worktrees. ScreenClip runs your project's validation command and opens the GitHub pull request.
- Grok Bot works remotely once you connect its webhook. ScreenClip pushes the approved screenshots to a branch in your repository and tracks the pull request Grok Bot opens.
- Answer local-agent questions from the report and follow progress in the queue. Codex permission requests, including connector tools such as Computer Use, are answered in ScreenClip.
- A report that is waiting for your answer does not hold up the queue: the next report starts, and the waiting one carries on when you reply.
- If you are away, Codex is told to continue without your answer after 10 minutes: questions get the safest default and permission requests are declined. Change the wait or turn it off in **Settings → Connections → AI agent → Continue without my answer**.
- Claude Code runs in its automatic permission mode, so it does not stop mid-turn for approvals.
- Fix pull requests include a Before / After comparison: your report screenshot and the agent's retested result.

## Follow the fix

- Track reports and pull requests from the menu bar or report queue.
- Enable automatic merge per project when validation, checks, and review requirements pass.
- Find merged fixes under **To retest**, with notifications that bring you back to the report.
- Use the app and website in ten languages, with light and dark appearances.

## Install

1. Download **ScreenClip.dmg** from this release.
2. Open the disk image and drag **ScreenClip** into **Applications**.
3. Launch ScreenClip, grant Screen Recording permission, add your repository, and connect a coding agent.

The download targets **Apple Silicon Macs running macOS 14 or later**. You also need a local Git repository, GitHub CLI authenticated to your account, and one supported coding agent. Intel users can build from source.

The distribution app and disk image are signed with Developer ID, notarized by Apple, and stapled for Gatekeeper verification.

To verify the download, place `ScreenClip.dmg` and `SHA256SUMS` in the same folder and run:

```sh
shasum -a 256 -c SHA256SUMS
```

## Privacy, license, and limits

- Reports and captures are stored locally until you submit them. Coding agents may send submitted content through their configured services.
- Submitted screenshots are published to the project's GitHub repository: in the fix pull request for Codex and Claude Code, and on a `screenclip/` branch for Grok Bot. Anyone who can read the repository can see them, and there is no per-project switch. Only the annotated, redacted version is published, so redact anything private before submitting.
- ScreenClip collects no analytics or telemetry.
- Free for noncommercial use under **PolyForm Noncommercial 1.0.0**. Commercial licensing is available on request.
- Keep ScreenClip running and your Mac awake while a local agent works.
- Updates are installed by downloading a newer disk image; automatic updates are not included in 1.0.0.
- Live Claude Code and Grok Bot workflows, multi-monitor capture, and clean-machine installation still need broader qualification. See the repository roadmap and validation notes for current coverage.

# ScreenClip 1.0.3

Automatic updates, pull requests that open instantly, and reports that recover when their worktree was removed.

## New

- **Automatic updates.** ScreenClip checks for a new version once a day, downloads it in the background, and installs it the next time it quits. When an update is ready, an **Update to …** button in the menu bar popover installs it and relaunches. Settings → General → **Updates** turns automatic installation off and has **Check for Updates…**, which is also in the popover's **⋯** menu. This is the last version you need to download by hand. The daily check only downloads the update feed from GitHub Releases; it sends no system profile or usage data, and ScreenClip still collects no analytics or telemetry.
- **Pull requests open instantly.** A report's pull request description and its Before / After screenshots are loaded in the background and kept for the session, so they open complete instead of showing a spinner and broken images. Screenshots fit the window, and scrolling over the description scrolls the report.
- **Formatted summaries.** The agent's summary on a report renders its Markdown (headings, lists, bold, code) instead of showing the raw characters.
- **Clearer pull requests.** The default prompt add-on asks agents to start each pull request with **What was the issue**, **How we addressed it**, and how it was verified.
- **Version in Settings.** The bottom of the Settings window shows the version and build number.

## Fixes

- A report whose worktree was deleted outside ScreenClip now notices when its pull request is merged or closed on GitHub, instead of staying at **Needs you** or **PR open**. ScreenClip no longer starts an agent in a missing worktree; the report explains what happened, and **Continue** starts again in a new worktree.
- A fix whose agent could not take an After screenshot now opens its pull request with a note, instead of stopping at **Needs you**.
- The popover's **Screenshot task** and **Text task** buttons share the full width.
- The queue header has **Settings** next to **New capture**, a full-width search field, and even spacing between its buttons.

## Install

Download **ScreenClip.dmg** from this release, open it, and drag **ScreenClip** into **Applications**, replacing the older version. Your queue, projects and settings are kept. From 1.0.3 on, ScreenClip updates itself. Requirements, privacy and limits are otherwise unchanged from the [1.0.0 release notes](v1.0.0.md): Apple Silicon and macOS 14 or later.

The app and disk image are signed with Developer ID, notarized by Apple, and stapled. Updates are also signed with ScreenClip's update key, and the app refuses any that are not. To verify the download, place `ScreenClip.dmg` and `SHA256SUMS` in the same folder and run:

```sh
shasum -a 256 -c SHA256SUMS
```

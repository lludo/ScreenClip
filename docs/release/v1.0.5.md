# ScreenClip 1.0.5

Claude Code and Codex can check any project's ScreenClip reports, installed in one click from Settings, and reports whose fix you merged by hand move to **To retest** on their own.

## New

- **Check tasks from your agents.** Settings › Connections › **Check tasks from your agents** installs ScreenClip's MCP server for Claude Code or Codex. Click **Install**, start a new agent session in any project, and ask “Check this project's ScreenClip tasks.” The agent sees what is open, in progress, and blocked for the project it is working in, and can read each report's details. The server only reads your queue: agents cannot change, send, or close reports.
- **Copy command** shows the same install as a Terminal command, and **Copy JSON** sets up other MCP apps, such as LM Studio.
- An agent can name the project by its folder, any folder inside it, a linked Git worktree, or the project's name. It can also list every project with its counts, and the blocked reports across all of them.

## Fixes

- A report that stopped before opening its pull request, whose branch was then pushed and merged on GitHub by hand, now moves to **To retest** and links that pull request. Before, it stayed under **Needs you** until you archived it. ScreenClip only looks a merge up this way when the report's worktree is gone, so no unpushed work is involved.
- A report whose pull request is closed without merging moves to **Needs you** and says so. Before, it stayed under **PR open**, counted as in progress, with nothing left to merge. Choose **Continue** to open a new pull request from the same branch, or archive the report. It can also be moved to another project again.
- After an update, agents use the new MCP server right away: ScreenClip refreshes the copy they run each time it starts.

## Install

If you have 1.0.3 or later, ScreenClip installs this update on its own: it shows **Update to 1.0.5** in the menu bar popover once it is downloaded, or installs it the next time ScreenClip quits. **Check for Updates…** in the popover's **⋯** menu checks right away.

From 1.0.2 or earlier, download **ScreenClip.dmg** from this release, open it, and drag **ScreenClip** into **Applications**, replacing the older version. Your queue, projects and settings are kept. Requirements, privacy and limits are otherwise unchanged from the [1.0.0 release notes](v1.0.0.md): Apple Silicon and macOS 14 or later. The MCP server runs only on your Mac and sends nothing anywhere.

The app and disk image are signed with Developer ID, notarized by Apple, and stapled. Updates are also signed with ScreenClip's update key, and the app refuses any that are not. To verify the download, place `ScreenClip.dmg` and `SHA256SUMS` in the same folder and run:

```sh
shasum -a 256 -c SHA256SUMS
```

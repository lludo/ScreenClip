The whole loop

Capture it, ship the fix, retest it.

A clipped button or a confusing label is enough. You keep moving. ScreenClip holds the report and the pull request.

  1. 01

    Capture

    Press Cmd Shift 2 and drag a region of a website or a Mac app. The shortcut can be changed in Settings.

  2. 02

    Annotate

    Add a note, an arrow, a shape, or text. A screenshot alone is enough. Redaction is a box you draw, flattened to opaque black.

  3. 03

    Agent

    Codex and Claude Code work on this Mac, in their own Git worktree. Grok Bot is remote, and only after you save a webhook and opt that project in.

  4. 04

    Pull request

    For Codex and Claude Code, ScreenClip runs your validation command and opens the pull request. Grok Bot opens it from the branch ScreenClip pushed.

  5. 05

    Merged

    With automatic merge on, ScreenClip merges after validation, checks, and review rules pass. It does not skip required reviews. A merge is not a deploy.

  6. 06

    Retest

    Merged reports move to To retest. A new capture on the same report continues that work. Leave the Mac awake while Codex or Claude Code runs.

The Mac app

The capture, then the queue.

Related screenshots stay on one report. Codex and Claude questions are answered in ScreenClip. Grok Bot questions stay in Grok Bot’s chat.

  • Websites and native Mac apps

Local first

What stays on the Mac, and what can leave.

ScreenClip has no account and no analytics. You choose the agent, the repository, and whether a project may send screenshots anywhere.

On this Mac

Reports, screenshots, notes, and project settings live in Application Support. A Grok Bot webhook, if you save one, stays in the Keychain. Codex and Claude Code see the approved screenshot only as a local agent.

What can leave

GitHub receives the branch and pull request opened with the GitHub CLI you already use. Those pull requests do not attach the screenshot by default. Grok Bot receives approved screenshots only after you opt that project in.

Redaction is a box you draw

The redact tool is a rectangle. ScreenClip flattens it to opaque black. Arrows, pen strokes, shapes, and text do not hide the pixels underneath. The unredacted crop is not kept.

From a screenshot to a pull request.

Capture a region on your Mac, mark what matters, and hand it to Codex, Claude Code, or Grok Bot. ScreenClip tracks the GitHub pull request, merges when you allow it, and keeps the result for retest.

How it works

Capture it, ship the fix, retest it.

A clipped button or a confusing label is enough. You keep moving. ScreenClip holds the report and the pull request.

  1. 01

    Capture

    Press Cmd Shift 2 and drag a region of a website or a Mac app. The shortcut can be changed in Settings.

  2. 02

    Annotate

    Add a note, an arrow, a shape, or text. A screenshot alone is enough. Redaction is a box you draw, flattened to opaque black.

  3. 03

    Agent

    Codex and Claude Code work on this Mac, in their own Git worktree. Grok Bot is remote, and only after you save a webhook and opt that project in.

  4. 04

    Pull request

    For Codex and Claude Code, ScreenClip runs your validation command and opens the pull request. Grok Bot opens it from the branch ScreenClip pushed.

  5. 05

    Merged

    With automatic merge on, ScreenClip merges after validation, checks, and review rules pass. It does not skip required reviews. A merge is not a deploy.

  6. 06

    Retest

    Merged reports move to To retest. A new capture on the same report continues that work. Leave the Mac awake while Codex or Claude Code runs.

Coding agents

Codex, Claude Code, or Grok Bot.

Choose a default in Settings, or pick an agent for a new report. A follow-up capture stays with that report’s agent.

Codex

On this Mac, in an isolated Git worktree. It does not push or open the pull request itself. ScreenClip runs your validation command and opens it. You answer questions on the report.

Claude Code

On this Mac, in its own Git worktree. ScreenClip opens the pull request. Questions show up on the report, and you answer them there.

Grok Bot

Remote. Nothing is sent until you save a webhook and turn on sending for that project. Grok Bot opens the pull request from the branch ScreenClip pushed. Questions stay in Grok Bot’s chat.

What you need

  • macOS 14 or later
  • A local Git repository for the app you are testing
  • Codex CLI, Claude Code, or a Grok Bot webhook
  • GitHub CLI, for pull requests and for Grok Bot

Leave ScreenClip running, and the Mac awake, while Codex or Claude Code works. Grok Bot keeps working if the Mac sleeps. ScreenClip updates that pull request the next time it is open.

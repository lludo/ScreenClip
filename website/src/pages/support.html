What you need to run it

  • macOS 14 or later.
  • A local Git repository for the project you are testing. Add it in Settings, with the website addresses or Mac app bundle IDs that should route to it, and a validation command.
  • At least one agent: Codex CLI with app-server, Claude Code, or Grok Bot (a webhook URL and Authorization header). Grok Bot also needs Allow sending screenshots to the external assistant turned on for that project.
  • GitHub CLI, logged into GitHub. ScreenClip uses it to open pull requests, and to push screenshots for Grok Bot.
  • Screen Recording permission, so ScreenClip can capture the region you select.

Leave ScreenClip running, and the Mac awake, while Codex or Claude Code works. Grok Bot keeps working if the Mac sleeps. ScreenClip updates that pull request the next time the app is running.

Building from source

@@SOURCE_HTML@@ The repository README is the build guide: copy the local signing example, open the Xcode project, and run the ScreenClip scheme. You need macOS 14 or later and Xcode 16 or later with Swift 6.

If capture fails

Use Check screen access in Settings. After you change access in System Settings, use Check again or Reopen app from the permission banner. Diagnostics are written to ~/Library/Application Support/ScreenClip/capture-diagnostics.log and do not include screenshots, notes, browser URLs, or window titles. The repository README has the screen-recording reset steps.
